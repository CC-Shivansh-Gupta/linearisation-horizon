# linearisation-horizon

Over what horizon does the first-order linearisation of a learned world model's latent dynamics (TD-MPC2) predict the
model's own nonlinear response?

This repository is preregistered. Read [`PREREGISTRATION.md`](PREREGISTRATION.md) first. Every numeric parameter is
in [`config/prereg.yaml`](config/prereg.yaml).

It is separate from the two completed Hankel-structure studies
([hankel-hierarchy](https://github.com/CC-Shivansh-Gupta/hankel-hierarchy)). No outcome here changes their verdicts,
and it uses only checkpoints that they never loaded.

**Commit history is part of the protocol.** The first commit is the freeze. It contains only this README, the
protocol and its parameters. Nothing result-bearing runs until the reviewer authorises it after the freeze.
